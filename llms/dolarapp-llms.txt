# DolarApp (ARQ)

> DolarApp — rebranded to ARQ in March 2026 — is a Latin American cross-border fintech
> founded in Mexico in 2022. It provides digital dollar (USDc) and euro (EURc) accounts,
> US ACH/wire receiving details, international cards, interbank-rate FX, bulk payouts and
> corporate cards to consumers and businesses in Mexico, Argentina, Colombia and Brazil.
> This file is generated by API Evangelist from public sources; DolarApp/ARQ publishes no
> llms.txt of its own (https://www.arqfinance.com/llms.txt returned 404 on 2026-08-12).

## API surface

- [Private application API host](https://api.dolarapp.com/): serves the DolarApp/ARQ
  mobile and business web applications. Anonymous requests return HTTP 403. No public
  developer program, documentation, OpenAPI, GraphQL SDL, AsyncAPI, MCP server or agent
  card was found on any host.
- [DolarApp Status API](https://status.dolarapp.com/api/v2/summary.json): public,
  unauthenticated Atlassian Statuspage v2 JSON — overall status, ten monitored components
  (sign up, sign in, website, and card payments / bank transfers for AR, MX, CO and US),
  incidents and scheduled maintenances. The only anonymous machine-readable HTTP surface.
